# 极光数独 (Aurora Sudoku) 🌌

一款好玩、好看、手感极佳的现代数独 Web 单页应用。采用 **Vite + React + TypeScript + Tailwind CSS** 开发，无后端依赖，所有进度与历史战绩保存在浏览器的 `localStorage` 中。

---

## ✨ 核心特性

### 1. 唯一解数学保障 & 难度分级
- **唯一解算法校验**：生成题目时通过高效 MRV（Minimum Remaining Values）回溯求解器进行自检（`countSolutions <= 1`），保证每一道题**严格有且仅有唯一解**。
- **三种难度模式**：
  - **简单 (Easy)**：~38 个初始已知数，适合新手轻松上手
  - **中等 (Medium)**：~31 个初始已知数，兼具趣味与挑战
  - **困难 (Hard)**：~25 个初始已知数，考验逻辑推演与候选数排除

### 2. 极致手感与交互体验
- **手感反馈与拟真音效**：基于 Web Audio API 实现纯算法合成音效（落子轻脆弹响、候选笔记微声、错误微震警示、提示魔法微光音、通关凯旋和弦），零音频资源依赖，低延迟、秒触发，支持随时一键静音。
- **光标十字线与同数高亮**：
  - 点击格子自动高亮同行、同列、同九宫格十字区域；
  - 选中数字即时高亮全盘所有相同数字，清晰直观；
  - 冲突格（同行/同列/同宫出现重复数字）震动标红警示。
- **全键盘与触控友好**：
  - 方向键 (`↑` `↓` `←` `→`) 或 `W` `A` `S` `D` 移动光标
  - 数字键 `1` ~ `9` 填入数字 / 候选数
  - `Backspace` / `Delete` / `0` 擦除选中格
  - `N` 或 `空格键` 快速切换【笔记/候选数】模式
  - `H` 触发智能提示
  - `Z` / `Ctrl+Z` 撤销，`Y` / `Ctrl+Y` 重做

### 3. 完整游戏闭环
- **候选数 (Pencil Marks) 模式**：每个空格支持标注 1~9 候选笔记，填入正式数字时自动清理相关行、列、九宫格中的同名候选数。
- **实时错误检测**：填错数字实时标红，并可随时在【设置】中开关。
- **智能提示系统**：每局限定 3 次提示，智能定位并填入正确数值。
- **计时与防窥暂停**：支持毫秒级计时与暂停遮罩。
- **胜利结算与礼花特效**：通关时触发彩带礼花、通关用时统计、历史新纪录判定以及一键复制战报分享。
- **每日一题 (Daily Challenge)**：基于当天日期种子（Mulberry32 PRNG）确定性生成，全网同一日题目完全一致，支持连胜天数打卡统计。
- **本地成绩排行榜**：按难度记录最快通关时间、平均耗时、通关局数与胜率。

## 🚀 快速启动

### 运行开发服务
```bash
npm install
npm run dev
```
打开浏览器访问 [http://localhost:5173](http://localhost:5173) 即可畅玩。

### 运行唯一解冒烟测试
```bash
npm test
```
终端将自动对各难度及每日一题进行生成和唯一解算法自检，输出详细用时与已知数统计。

### 生产环境打包
```bash
npm run build
```
打包输出至 `dist` 目录，可直接托管至任何静态托管平台（GitHub Pages、Vercel、Cloudflare Pages 等）。
