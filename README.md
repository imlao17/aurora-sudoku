# 知数 (ZhiShu Sudoku)

知行合一，数见真知。一款纯粹·专注·逻辑之美的现代纸墨数独系统。基于 **Vite + React + TypeScript + Tailwind CSS** 开发，无后端强依赖，100% 离线 PWA 支持，全平台零延迟畅玩。

---

## 核心特性一览

### 1. 多规格规格矩阵与启蒙进阶
- **4×4 幼儿启蒙 (2×2 宫)**：16 格大靶心触控，专为 4~7 岁儿童打造，30 秒沉浸通关，培养空间排他直觉。
- **6×6 亲子进阶 (2×3 矩形宫)**：36 格进阶推演，平滑过渡行列宫交叉排他逻辑。
- **9×9 专业经典 (3×3 九宫格)**：81 格全规格标准数独，涵盖简单、中等、困难与每日挑战。
- **确定性每日一题**：基于日历日期种子（Mulberry32 PRNG）全局统一确定性生成，支持跨年跨月连胜打卡统计。
- **数学唯一解保证**：生成阶段内建 MRV（Minimum Remaining Values）回溯检验器，100% 保证题目有且仅有唯一解。

### 2. 扁平认知符号与拼音启蒙
- **经典数字**：标准阿拉伯数字。
- **生肖萌宠**：汉字动物意象（猫、狗、兔、熊、鹿、鸟、鱼、蝶、马），搭配正上方标准汉语拼音与声调（Ruby Pinyin Annotation），实现益智解题与识字认音双重教学价值。
- **极简几何**：单色纯平几何符号（●、▲、■、◆、▼、◈、◉、◎、⬢），黑白禅意，随主题色阶自适应。
- **拼音启蒙**：单韵母（a, o, e, i, u, ü）与声母认知。
- **东方汉字**：春夏秋冬、日月水火木金、传统天干地支四季意象。

### 3. 数独解题方法百科与逐步求解器
- **23 种人类逻辑推演法**：
  - 基础级：唯余数法、隐性唯一、行列排除、宫内排除；
  - 进阶级：区块排除、数对（显性/隐性）、三链数、四链数；
  - 大师级：X-Wing、XY-Wing、Swordfish、单链推理等。
- **每项技巧配备完整教学闭环**：观察条件、逻辑推演、结论落地 3 步拆解，动态高亮目标格与条件格，支持即时小测验与实战演练。
- **逐步教学求解器 (Visual Step-by-Step Solver)**：随时将当前残局一步一步以人类解题视角动画推演至终局，支持调速、步进与回退。

### 4. 纸墨美学与触控打磨
- **三大纸墨主题**：
  - 北欧纸白 (Nordic Paper)：极简素净，柔和纸质灰白；
  - 抹茶清心 (Matcha Zen)：温润茶青，宁静护眼；
  - 纸墨黑夜 (Deep Ink Night)：纯正暗夜护眼，纯色线条与玉白字形。
- **儿童大靶心交互**：
  - 4×4 模式按键高度提升至 82px ~ 96px，圆角超大饱满，按键间隙增宽，杜绝误触；
  - 盘面字号智能放大至 4xl ~ 6xl，视距友好。
- **Web Audio 纯合成音效**：
  - 基于声学振荡器（OscillatorNode）合成纸笔微弹、清脆落子、提示微音与通关和弦，零外部音频资源下载，秒级响应。

### 5. 账号管理体系与游客数据无损合并
- **本地多账号体系**：支持快速切换账号、设置专属纸墨印章头像与昵称。
- **智能合并机制 (Account Merge)**：
  - 游客游玩后注册或登录已有账号时，自动比对最佳通关记录、累计胜局、历史连胜与成就勋章；
  - 自动无损取优合并，杜绝数据覆盖或游玩成果丢失。
- **云端同步预留架构**：内置数据序列化/反序列化与时间戳仲裁协议，支持后续无缝接入云端多端同步。

### 6. 数据统计与成就荣誉墙
- **战绩数据看板**：各难度胜率、通关耗时分布、连胜折线、每日打卡记录。
- **10 大荣誉勋章**：初出茅庐、疾风如电、不着一字、无瑕之局、七日长风、博学多通等，达成自动解锁并推送通知。

## 工程规范与技术栈

- **框架**：React 19 + TypeScript + Vite 8
- **样式**：Tailwind CSS + Lucide Icons（纯矢量线条，全站 0 个 3D/彩色 Emoji）
- **测试**：Vitest 5 + Happy DOM + Testing Library (165+ 测试用例，覆盖率 90%+)
- **代码规范**：Oxlint（0 警告、0 错误严格模式）
- **性能优化**：React.memo 浅对比隔离、组件级细粒度渲染防护、PWA 离线缓存 Service Worker

## 快速上手

### 启动开发环境
```bash
npm install
npm run dev
```
打开浏览器访问 [http://localhost:5173](http://localhost:5173) 即可开始。

### 运行全套自动化测试
```bash
npm test
```

### 代码规范检查
```bash
npx oxlint --deny-warnings
```

### 生产严苛准入自检
```bash
npx tsx scripts/prod-readiness-check.ts
```

### 生产打包
```bash
npm run build
```
打包产物位于 `dist/`，零服务器配置即可托管至 GitHub Pages 或静态 CDN。
