# 阶段一技术方案设计：生成器大战与难度评级体系

## 1. 概述与目标

在数独应用中，题目的生成质量直接决定了游戏的核心乐趣与手感。本阶段目标：
1. **实现 3 种设计思路迥异的挖空生成算法**：
   - **算法 A（随机挖空 + 唯一解校验）**：追求随机性与局部集群感，开局快速无拘束。
   - **算法 B（中心/轴对称 pattern 挖空）**：经典报刊与比赛级美学设计，点阵视觉平衡和谐。
   - **算法 C（基于技巧需求的定向挖空）**：由人类逻辑推演驱动，定向消除低阶解题路径，强制形成高阶技巧（Pointing、Pairs、Intersections 等）。
2. **构建可解释的人类思维逻辑难度评级器 (Human-Logic Difficulty Rater)**：
   - 绝非简单按“挖空数量”粗暴定级，而是通过模拟人类解法（不进行暴力试错），分析题目解开所需的人类技巧阶数与步数，给出精确定量难度分（Difficulty Score）及技巧链。
3. **真实基准评测报告 (20题 × 3算法 = 60题完整实测)**：
   - 输出生成耗时、难度分分布、技巧覆盖率对比表。
4. **难度档位绑定**：
   - 为【简单】、【中等】、【困难】档位匹配最合适的生成算法与参数。

## 2. 三种挖空算法架构设计

### 算法 A：随机挖空算法 (Random Digging + Uniqueness Backtracking)
- **原理**：
  1. 生成一个合法的终盘 `Grid`。
  2. 生成全盘 81 个单元格坐标的随机排列洗牌列表 `coords`。
  3. 依次尝试移除单元格的值 `grid[r][c] = 0`。
  4. 调用硬件级位运算求解器进行唯一解检验：`countSolutions(grid, 2) === 1`。
  5. 若破坏唯一解，则立刻回退当前格子；若保持唯一解，则确认挖空。
  6. 重复直到达到目标已知数或全盘扫描完毕。
- **特点**：实现直接、无图案规则限制，容易出现局部密集或稀疏的不规则特征。

### 算法 B：中心对称 pattern 挖空算法 (Symmetric Pattern Digging)
- **原理**：
  1. 生成合法终盘 `Grid`。
  2. 生成 180° 中心对称点对序列：$(r, c)$ 与 $(8-r, 8-c)$。
  3. 坐标列表随机洗牌后，以“对 (Pair)”为单位尝试挖空。
  4. 同时将对称的两格置为 0，调用 `countSolutions(grid, 2)`。
  5. 仅当移除这对数字后解依然严格唯一，才保留挖空；否则两者同时恢复。
  6. 中心格 $(4, 4)$ 作为独立单格处理。
- **特点**：盘面呈现完美的中心对称几何美感，是数独世锦赛与专业报刊的黄金标配。

### 算法 C：基于技巧需求的定向挖空算法 (Technique-Targeted Digging)
- **原理**：
  1. 先进行基础对称挖空，使题目降至初级形态。
  2. **逻辑推演循环与定向击穿**：
     - 在挖空过程中，调用**难度评级器 (Difficulty Rater)** 进行非回溯逻辑求解。
     - 若当前盘面完全由基础技巧（如纯 Naked Single 唯一余数法）就能解穿，则说明难度不足；
     - 评级器定位出那些“直接暴露了唯余解”的已知数线索格，将其作为**优先挖空目标**；
     - 挖去关键阻碍线索，打破唯余通路，逼出高阶技巧（如行/列/宫的隐性唯一数 Hidden Single、锁定候选数 Pointing Pair、数对 Naked/Hidden Pair）；
     - 每次定向挖空均严格校验 `countSolutions(grid, 2) === 1`。
- **特点**：生成的题目技巧指向性极强，绝无“靠单纯看空格就能一眼填到底”的假难题，逻辑推理性极高。

## 3. 人类逻辑难度评级器架构设计

难度评级器模拟人类玩家从空白候选数草稿开始推演，定义 6 个认知难度阶梯：

| 技巧阶数 | 技巧名称 (Technique) | 逻辑原理说明 | 技巧单步基础权重 |
| :---: | :--- | :--- | :---: |
| **L1** | **Naked Single (唯一余数)** | 某单元格在同行、同列、同九宫格已被占满 8 个数字，仅剩最后 1 个候选数 | 10 |
| **L2** | **Hidden Single (隐性唯一数)** | 某数字在某行、某列或某九宫格中，仅能存在于唯一的一个单元格中 | 25 |
| **L3** | **Pointing Pair / Triple (锁定候选数)** | 某九宫格内的某数字全部局限在同一行或同一列，从而排除该行/列其它宫的该候选数 | 60 |
| **L4** | **Box-Line Reduction (行列对宫排除)** | 某行或某列内的某数字全部局限在同一九宫格，从而排除该宫内其它位置的该候选数 | 80 |
| **L5** | **Naked Pair / Triple (显性数对/三数组)** | 同一区域内 $N$ 个格子的候选数完全由相同的 $N$ 个数字组成，可排除该区域其余格中这些数字 | 120 |
| **L6** | **X-Wing (双链四角消除)** | 某数字在两行中仅出现在相同的两列，形成矩形，可排除这两列其它行中的该数字 | 200 |

### 难度分计算公式
$$\text{Score} = \text{Base} + (\text{Peak Technique Weight} \times 2.0) + \sum (\text{Technique Weight} \times \text{Frequency}) + (\text{Empty Cells} \times 3)$$
- 若仅靠逻辑推导完全解开：评定为对应难度级别；
- 若无法纯靠上述技巧推开（必须试错假定）：标记含有深层链或高级技巧。

## 4. 20 题实测对比与验收指标

针对三种算法分别批量生成 20 道唯一解有效题目（共 60 题），由独立基准脚本自动采集数据：
1. **生成效率**：平均耗时（ms）、单题最小/最大耗时；
2. **难度分分布**：最低分、最高分、平均分、标准差；
3. **已知数与空格数**：平均已知数 (Clues)；
4. **技巧覆盖率**：需要 Naked Single、Hidden Single、Pointing、Pairs、Advanced 的题目占比。

## 5. 难度档位与算法绑定规则

- **简单档位 (Easy)** $\to$ **绑定算法 B（对称美学挖空）**
  - 理由：对称图形带来优雅舒适的第一印象；目标保留 36~40 个已知数；技巧集中于 L1 (Naked Single) 与基础 L2 (Hidden Single)，直观流畅。
- **中等档位 (Medium)** $\to$ **绑定算法 A / B 混合优化**
  - 理由：已知数降至 30~34 个，要求全盘兼具对称美感，且必须引入大量行/列隐性唯一数搜索。
- **困难档位 (Hard)** $\to$ **绑定算法 C（技巧需求定向挖空）**
  - 理由：已知数压缩至 24~28 个，经过定向剔除低阶线索，强制包含 Pointing / Pairs / Reduction 等多重推导技巧，杜绝“无脑填空”。
